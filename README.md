# Digital Student Portfolio Hub (WD-T1-076)

Student showcase page with dynamic tabs for **Projects**, **Certifications** and **Skills**.
Built with HTML, Tailwind CSS (CDN) and vanilla JavaScript.

## Features
- Dynamic tabs (click, arrow-key navigation, URL hash, remembers last tab)
- Projects: live search + technology filter
- Certifications: card grid
- Skills: grouped, animated progress bars
- Dark / light mode, fully responsive
- All content in one `portfolio` object in `script.js`

## Run
Open `index.html` in a browser or use VS Code Live Server.

## Deploy (GitHub Pages)
Settings → Pages → Deploy from branch → `main` / root.
